# Скины группировок по званиям

Цифра в конце имени = этап звания:

| Цифра | Звание   | Рейтинг   |
|------:|----------|-----------|
| 1     | Новичек  | 0–499     |
| 2     | Опытный  | 500–1999  |
| 3     | Ветеран  | 2000–4999 |
| 4     | Легенда  | 5000+     |

## Как положить файлы

Вариант A — по папкам (предпочтительно):

```
assets/avatars/factions/
  dolg/1.png … 4.png          # Долг
  svoboda/1.png … 4.png       # Свобода
  neutraly/1.png … 4.png      # Нейтралы
  bandity/1.png … 4.png       # Бандиты
```

Вариант B — имена как на рабочем столе:

```
assets/avatars/скины/Долг1.png
assets/avatars/скины/Свобода2.png
…
```

или

```
assets/avatars/скины/Долг/Долг1.png
```

## Импорт с рабочего стола

```bash
python3 scripts/import_faction_skins.py "/path/to/скины"
```

Скрипт подгоняет картинки под слот профиля **248×320** (cover-обрезка
по центру горизонтально, с прижатием к низу вертикально).
